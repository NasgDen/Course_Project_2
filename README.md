# Курсовой проект 2 - Поиск вакансий

## Описание

Данный проект - это консольное приложение написанное на языке программирования Python. Приложение взаимодействует с сайтом HeadHunter (hh.ru) по средствам механизма API.
API — это механизм, который позволяет различным программам взаимодействовать друг с другом, используя набор определенных правил. 
Приложение по заданному поисковому запросу получает список данные о вакансиях с api.hh.ru.
В приложении реализована фильтрация по ключевым словам, по диапазону зарплат, а так же сортировка по диапазону зарплат.
На выходе приложение выводит, заданное пользователем, количество вакансий.
Сохраняет полученный список вакансий в файл формата JSON. Реализована по добавлению и удалению вакансий из файла.

## Описание функций

1. Модуль base_api.py - Базовый абстрактный класс, определяющий интерфейс для работы с api запросами.
2. Модуль file_base_class.py - Базовый абстрактный класс, определяющий интерфейс работы с файлами.
3. Модуль head_hunter_api - Класс HeadHunterAPI для работы с api.hh.ru.
* Метод __api_connect - Приватный Метод подключения к api.hh.ru.
* Метод get_vacancies - Получение вакансий с hh.ru в формате JSON.
4. Модуль json_sever.py - Класс JSONSaver для работы с файлами формата JSON.
* Метод write_vacancy - Метод сохраняет список вакансий в файл формата JSON.
* Метод add_vacancy - Метод добавления данных в файл формата JSON.
* Метод read_vacancy - Метод чтения данных из файла формата JSON.
* Метод delete_vacancy - Метод удаления данных из файла формата JSON.
5. Модуль vacancy.py - Класс определяющий интерфейсы для работы с вакансиями.
* Метод cast_to_object_list - Метод создает список вакансий.
* Метод url_validate - Метод производит валидацию url адреса.
* Метод __str__ - Магический метод - определяет вывод информации об экземпляре класса в консоль.
* Метод __lt__ - Магический метод - реализует сравнение двух экземпляров класса Vacancy.
6. Модуль utils.py - Содержит вспомогательные функции для работы приложения.
* Функция convert_object_to_dict - Конвертация объектов класса Vacancy в список словарей.
* Функция filter_vacancies - Функция фильтрует список вакансий по заданным словам в наименовании вакансии.
* Функция get_vacancies_by_salary - Функция фильтрует список вакансий по диапазону зарплат.
* Функция sort_vacancies - Функция сортирует список вакансий по минимальной зарплате по убыванию.
* Функция get_top_vacancies - Функция получает заданное количество вакансий.
* Функция print_vacancies - Вывод информации о вакансиях в консоль.

## Установка

1. Клонируйте репозиторий:
```
git clone https://github.com/NasgDen/course-project_2
```
2. В PyCharm установите менеджер проекта poetry.
3. В PyCharm устанавливаем все зависимости проекта из файла pyproject.toml

## Использование:

1. Запустите файл main.py из корневой директории проекта.
2. Введите данные.
3. Просмотрите результат выполнения программы.
